## Delmarwa-chicken-coop

An ecommerce MERN application built for practicing and understanding the CRUD operations, MVC structure, code modularity, configuration setup for production and development, backend deployment, backend middleware and expanding my skillset in nodejs,expressjs and mongoose queires. Deployed frontend on vercel and backend on railway.

## It's still ongoing project.

## Currently Implemented

- **Product Catalogue**

  - Browse available products.
  - Product cards displaying product information.
  - Product detail pages with dynamic product routes.

- **Product Filtering**

  - Sidebar-based filtering for products.
  - Product browsing through the shop catalogue.

- **Shopping Cart**

  - Add products to the cart.
  - Manage product quantities.
  - Remove products from the cart.
  - View cart summary.

- **Checkout Flow**

  - Cart-protected checkout route.
  - Address form for shipping information.
  - Order creation after submitting the address.
  - Multi-step checkout flow using nested routes and React Router's `<Outlet />`.
  - Payment step connected to the created order.
  - Order confirmation page using the dynamic `orderId`.

- **Authentication & Protected Routes**

  - User account page.
  - JWT-based authentication using HTTP-only cookies.
  - Protected routes for authenticated functionality.

- **Admin Panel Foundation**

  - Implemented but but integrated to repo.

- **Routing**

  - Nested routes for shop, checkout, and admin sections.
  - Dynamic product detail routes.
  - Dynamic order routes.
  - Custom 404 / Not Found page.
